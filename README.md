# For You, Always

A personal romantic interactive site. Edit all names, photos, soundtrack paths, promises, and reasons in `src/config/love-config.ts`.

Photos live in `public/images`, and the current soundtrack is `public/audio/o-sanam.mp3`. Replace the files while keeping their paths, or update the configuration.

The site is deliberately no-index and uses no analytics. Local discovery of the 100 notes is stored only in the visitor’s browser.
